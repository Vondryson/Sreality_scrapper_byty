# Terraform

Terraform pro Google Cloud projekt `sreality-scrapper-504307` vznikne od tasku `M4-02` po uzavření nákladové brány `M0-05`.

Plánovaný rozsah zahrnuje Cloud SQL, Cloud Run services/job, Cloud Storage, IAM, Secret Manager vazby, Scheduler, monitoring a budget upozornění. Žádný produkční prostředek se v M0 z tohoto adresáře nevytváří.
