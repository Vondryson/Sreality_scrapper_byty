# Architecture Decision Records

ADR zachycují významná technická rozhodnutí, jejich kontext a důsledky. Produktová rozhodnutí zůstávají ve `specifikace.md`.

Doporučený název: `NNNN-strucny-nazev.md`.

Minimální struktura ADR:

```markdown
# Název

- Stav: navrženo / přijato / nahrazeno
- Datum: YYYY-MM-DD

## Kontext

## Rozhodnutí

## Důsledky
```
