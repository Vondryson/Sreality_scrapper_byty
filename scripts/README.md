# Scripts

Sem patří malé bezpečné nástroje pro validaci zdroje, profilování a provozní úlohy.

Každý skript musí:

- mít popsaný účel a příklad spuštění,
- používat sdílenou konfiguraci a klienty, pokud již existují,
- být ve výchozím stavu read-only nebo vyžadovat explicitní potvrzení změny,
- nezapisovat secrets ani osobní údaje do repozitáře,
- respektovat nízkou frekvenci požadavků na externí služby.
